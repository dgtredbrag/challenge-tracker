# Шаг за шагом — MVP

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере для быстрой проверки.
3. Для установки как PWA разместите папку на HTTPS-хостинге (например, GitHub Pages).
4. Откройте ссылку в Chrome/Safari и выберите «Добавить на главный экран» / «Установить приложение».

## Что работает
- Создание челленджей: делать / не делать, описание, срок, приз, личная причина.
- Список активных челленджей и экран «Сегодня».
- Календарь на весь срок с отметками выполнено / не выполнено.
- Записи дня: подпись, ощущения, одна фотография.
- Еженедельные рефлексии: три текстовых поля, настроение 1–5, до трёх фото.
- Прогресс, процент, текущая серия, прерванные дни, среднее настроение.
- Завершение челленджа и итоговые заметки.
- Локальное сохранение в браузере и базовый офлайн-кэш.

## Ограничения этого MVP
- Данные и фото хранятся в локальном хранилище браузера. Не очищайте данные сайта, иначе записи могут пропасть. Для большого количества фото лучше перейти на IndexedDB.
- Еженедельные push/local-уведомления пока не подключены: для надёжных уведомлений на iOS/Android потребуется отдельный слой разрешений и планировщик.
- Нет облачной синхронизации, аккаунтов и экспорта.
- Это PWA-прототип, не подписанный APK/IPA и не опубликованное приложение в магазинах.
